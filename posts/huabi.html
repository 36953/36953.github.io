36953画笔使用说明书

2026-11-13 · V1.0

上课投屏时，经常要在 CAD、PPT 或网页上临时圈重点。很多标注工具会直接画进软件，关掉又麻烦；浏览器白板又切不过去。 36953画笔做的事很简单：常驻托盘，需要时把当前画面定格下来涂画，讲完一关就结束，原来的程序原封不动。

下载： Releases 最新版 → HuaBi.exe（约 830 KB，单文件免安装）　·　 源码与说明

一、它适合什么场景

  • CAD / 图纸课：圈尺寸、标步骤，笔迹不会写进图纸
  • 投屏讲解：在任意窗口上临时划重点
  • 需要让学生看见你按了什么键（右下角有按键提示）
画面会定格。结束之后回到原来的软件，笔迹不会写进 CAD。

二、快速上手

  1. 双击 HuaBi.exe 启动，图标出现在系统托盘。
  2. 讲到需要标注时，按 Pause（可改）。
  3. 在定格画面上画；顶部工具栏可改颜色、粗细、工具。
  4. 再按 Pause 或 Esc 结束，回到正常桌面。
  5. 只有托盘右键里的「退出程序」才会真正关掉软件。

双击托盘图标，也可以开始 / 结束标注。

三、标注时怎么用

工具栏

定格后顶部会出现工具栏，从左到右大致是：

  • 颜色：红、黄、绿、蓝、白、黑
  • 粗细：细 / 中 / 粗（也可用滚轮微调）
  • 工具：画笔、直线、矩形、荧光、橡皮
  • 操作：撤销、清空、保存、结束

打开后默认是细的红画笔。橡皮会去掉碰到的整条线。

快捷键

  • Pause（默认）— 开始 / 结束标注
  • Esc — 结束标注
  • Ctrl+Z / Ctrl+Y — 撤销 / 重做
  • Ctrl+S — 保存到「图片\画笔」文件夹
  • 滚轮 — 调节粗细
  • 按住 Shift — 临时画直线
  • P / L / R / H / E — 画笔 / 直线 / 矩形 / 荧光 / 橡皮
  • 1～6 — 红、黄、绿、蓝、白、黑

标注时右键也可弹出菜单：撤销、重做、清空、保存、结束。

四、屏幕贴图

除了定格涂画，还可以把一块屏幕内容「钉」在最前面，方便对照着讲：

  • Ctrl+Alt+Q：拖出区域，松手后浮在最前
  • 可贴图可拖动，滚轮缩放；双击或点右上角关闭
  • 贴图上右键：复制、保存到「图片\画笔」、关闭全部
  • 剪贴板里已有图片时，托盘菜单选「贴上剪贴板图片」即可

五、托盘菜单

  • 开始 / 结束：与快捷键相同
  • 屏幕贴图：进入框选贴图
  • 贴上剪贴板图片
  • 使用说明：程序内帮助
  • 更换快捷键：Pause / Ctrl+Alt+D / Ctrl+Shift+D / Ctrl+`
  • 退出程序：真正退出

若提示快捷键被占用，换一个即可；也可以先双击托盘图标开始画。 偏好（快捷键、颜色、工具、线宽）写在程序旁的 huabi.ini。

六、按键显示

运行后，当前屏幕右下角会显示你按下的键，方便学生跟操作。 位置避开中间图纸和 CAD 底部命令行；进入定格涂画或框选贴图时会自动隐藏，结束后恢复。

七、从源码编译（可选）

需要 MSVC 或 MSYS2 的 g++。在项目目录运行：

build.bat

成功后生成 HuaBi.exe。详情见 GitHub 仓库。
