Tools

桌面程序链到 GitHub；网页工具都在浏览器里运行，名单和画不会上传。

  • 画笔

    上课用全屏标注。托盘常驻，Pause 定格涂画，笔迹不进 CAD。C++ / Win32，单 EXE。

  • 见报

    按日期下载人民日报等电子版 PDF，按版序合并整份报纸。C++ / Win32，单 EXE。

  • 白板

    画笔、橡皮、撤销，画完可导出图片。

  • 点名

    贴进名单后随机抽人，也可以分组。

  • 计时

    倒计时和秒表，时间到会变色并响一声。

  • 二维码

    把链接或文字变成二维码。
